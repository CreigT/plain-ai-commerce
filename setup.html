Setup Guide

  1. Import this GitHub repo into Vercel.
  2. Deploy with Framework = Other, no build command.
  3. In Vercel Settings → Environment Variables, add the values from .env.example.
  4. Create Stripe Payment Links for each product and paste the URLs.
  5. Redeploy. Visit /shop.html to test.

Need help? Check the README on GitHub.
